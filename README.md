# Sanchit's Portfolio

Personal portfolio website showcasing my background in Software Engineering and AI/ML, along with projects, education, skills, and contact details.

## Overview

This is a responsive single-page portfolio built with plain HTML, CSS, and JavaScript.

It includes:
- Sidebar navigation (desktop) + mobile menu
- Hero section with typing animation
- About section with profile highlights
- Education timeline
- Skills with animated progress bars
- Projects showcase with GitHub links
- Contact form UI and social links

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
- Font Awesome (icons)
- Google Fonts (Poppins)
- particles.js (background effect)

## Run Locally

Since this is a static website, you can run it with any local server.

### Option 1: Python HTTP Server

```powershell
cd d:\Project\portfolio
python -m http.server 5500
```

Open:

`http://127.0.0.1:5500/`

### Option 2: VS Code Live Server

1. Open the folder in VS Code.
2. Install the Live Server extension.
3. Right-click `index.html` and click `Open with Live Server`.

## Customization

- Update profile image in `assets/images/image.jpg`
- Update section content in `index.html`
- Update colors/layout/theme in `css/style.css`
- Update animations and interactivity in `js/script.js`
